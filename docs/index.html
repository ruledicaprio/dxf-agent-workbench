DXF Agent Workbench

Orthographic renderer for large 3D DXF meshes

Deterministic TOP · FRONT · RIGHT projections with automatic centering and scaling. Built for engineering drawings and high-poly CAD models.

python ≥3.9 status ready license MIT version v0.1.0

What it does

  • Loads large DXF meshes (tested beyond 2 M faces)
  • Centers and normalizes geometry automatically
  • Renders clean orthographic views (TOP / FRONT / RIGHT + optional ISO)
  • Exports high-resolution PNG (default 3200 px)
  • Optional wireframe or outline DXF export

Install

shell
# clone & install git clone https://github.com/ruledicaprio/dxf-agent-workbench.git cd dxf-agent-workbench python -m venv .venv && source .venv/bin/activate pip install -e .

Usage

shell
dxf-ortho model.dxf --size 3200 --views top,front,right

Output is written to a folder next to the input file. See dxf-ortho --help for all options.

Stack

Python · ezdxf · trimesh · numpy · matplotlib · OpenCV
